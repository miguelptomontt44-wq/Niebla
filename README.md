# DungeonFog

Plugin para Paper 26.3 que crea zonas de niebla (con particulas) ideales para dungeons y laberintos.

## Uso rapido
1. Parate en una esquina y `/fog pos1`, ve a la esquina opuesta y `/fog pos2`
2. `/fog create mazmorra1`
3. `/fog set mazmorra1 color light_gray` (cualquier color de tinte de Minecraft o `#RRGGBB`)
4. `/fog set mazmorra1 density 10` (menos = mas sutil)

Permiso: `dungeonfog.admin`
